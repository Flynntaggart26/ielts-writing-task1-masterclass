An interactive, offline-first workbook for **IELTS Academic Writing Task 1**.
Every chart type the exam can throw at you — each one twice — with Band 9 model answers,
examiner analysis, and a built-in exam simulator.

## 🚀 Quick Start

No install, no build. Either:

- **Online** — open the live site above 👆, or
- **Offline** — download `index.html` and open it in any browser

## 📊 14 Tasks — 7 Chart Types × 2

| # | Type | Topic |
|---|------|-------|
| 1–2 | 📈 Line Graph | Coffee consumption · Renewable energy share |
| 3–4 | 📊 Bar Chart | International students · Weekly working hours |
| 5–6 | 🥧 Pie Chart | Energy sources in France · Why study abroad |
| 7–8 | 📋 Table | House prices · Smartphone ownership |
| 9–10 | ⚙️ Process Diagram | Instant coffee production · The water cycle |
| 11–12 | 🗺️ Map | Village change 1930→2010 · Hospital redesign (future plan) |
| 13–14 | 🔀 Mixed Charts | Cinema visits (bar + pie) · CO₂ emissions (table + line) |

Every task includes: authentic exam prompt + chart + data table + **Band 9 model answer**
(164–191 words, color-coded: Introduction / Overview / Detail 1 / Detail 2) +
examiner analysis + golden phrases + writing box.

## ✨ Features

- **Paraphrase Lab** — 5-question interactive quiz with instant feedback
- **Examiner scoring guide** — what TA / CC / LR / GRA Band 9 really requires
- **20-minute exam simulator** — timer with Plan → Write → Check phases
- **Live word counters** with the 150-word goal bar, progress saved via `localStorage`
- **Vocab bank** (6 tabs: trend, comparison, pie/table, process, map, overview frames)
- **7-day study plan**, Band 9 checklist, difficulty badges, dark mode 🌙
- Responsive + print/PDF friendly

## 🗓 Suggested 7-Day Plan

| Day | Focus |
|-----|-------|
| 1 | Line + Bar (Tasks 1–2) — overviews + trend language |
| 2 | Bar + Pie (Tasks 3–4) + Paraphrase Lab quiz |
| 3 | Pie + Table (Tasks 5–6), timed writing of Task 7 |
| 4 | Table (Task 8) + rewrite Task 7 (2nd attempts ≈ +0.5 band) |
| 5 | Process (Tasks 9–10) — passive voice drills |
| 6 | Map (Tasks 11–12) — past vs. future passive |
| 7 | Mixed (Tasks 13–14) + full timed mock of Task 14 |
